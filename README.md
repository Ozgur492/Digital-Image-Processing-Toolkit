# 🖼️ Digital Image Processing Toolkit

A comprehensive desktop image processing application built with Python, featuring real-time preview and an intuitive GUI.

![Python](https://img.shields.io/badge/Python-3.8+-blue.svg)
![OpenCV](https://img.shields.io/badge/OpenCV-4.x-green.svg)

## ✨ Features

### Basic Operations
- Grayscale conversion
- Horizontal & Vertical flip
- 90° Clockwise & Counter-clockwise rotation

### Affine Transformations
- Arbitrary angle rotation
- Scaling with size constraints
- Translation (dx, dy)
- Shear X / Shear Y

### Intensity Operations
- Negative image
- Auto contrast stretch
- Gamma correction (0.1 - 3.0)

### Filtering
- Mean, Gaussian, Median filters
- Laplacian edge detection
- Sobel X / Y operators
- Canny edge detection

### Histogram & Morphology
- Histogram visualization & equalization
- Otsu's thresholding
- Erosion / Dilation / Opening / Closing

## 🛠️ Tech Stack

- Python 3.8+
- OpenCV
- NumPy
- Pillow
- Matplotlib
- Tkinter + ttkbootstrap

## 🚀 Installation
```bash
pip install opencv-python numpy pillow matplotlib ttkbootstrap
python main.py
```
